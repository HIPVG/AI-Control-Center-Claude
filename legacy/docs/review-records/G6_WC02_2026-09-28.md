## Implemented boundary

`day_admission()` is read-only and consumes the existing WC-01 `RunIntent`.
It never creates a run, selects a Day, starts a thread, changes Git, probes
credentials, or invokes a model.  It returns exactly one of:

- `ADMISSIBLE` with next state `PREFLIGHT`; or
- `BLOCKED` with a concrete `HUMAN_ACTION_REQUIRED` or
  `EXTERNAL_ACTION_REQUIRED` blocker.

The `LocalLLMDayProgram.admission()` boundary exposes the same result without
mutating the persisted Day snapshot.  Wiring a user Go action to create a
RunIntent and call this boundary remains WC-04; this card neither selects nor
starts a Day.
