## Implemented boundary

Day selection is now browser-local: changing the selector creates no POST,
RunIntent, persisted Day selection, or external action. The UI reports this
explicitly.

Go sends only a typed `{selected_day}` payload to
`POST /api/local-llm/day/go`. The server creates a versioned immutable RunIntent
using server-owned contract, policy, config and Git fingerprints plus the fixed
1800-second, two-attempt, zero-cost limits. The same run ID is carried in the
RunIntent and admission handoff. Browser-supplied permission or prerequisite
facts are rejected by the request model.

The endpoint calls the WC-02 admission boundary but never selects a persisted
Day, starts a Day thread, or invokes the existing actual-start endpoint. Unknown
server-owned permission fails closed; a clean isolated fixture with explicitly
injected observed prerequisites reaches only `ADMISSIBLE`/`PREFLIGHT`.
