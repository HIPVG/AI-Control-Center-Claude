## Implemented boundary

`LocalLLMDayProgram.days()` remains read-only and now returns one catalog entry
for every Day 1–14. Each entry includes contract version and fingerprint,
required Evidence types, authoritative source scope and presence, required
preflight inputs, a concrete admission result, and `execution_started: false`.

A valid configured Day with all authoritative sources is catalog-admissible only
to `PREFLIGHT`; it still requires a matching RunIntent and the WC-02 runtime
preflight. Missing, duplicate or invalid Day definitions block only the affected
Day as `INPUT_BLOCKED`. Invalid global configuration, unregistered Evidence and
missing authoritative sources also fail closed with concrete reasons. The method
does not select a Day, create a run, mutate LocalLLM-Lab, or claim execution.
